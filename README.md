# Red Arrow Hub

A free, offline-friendly AI, IT and cybersecurity learning site for students at Red Arrow High School in San Nicolas, Pangasinan, Philippines.

**This is a private preview.** It is not ready for class use yet. Before students use it, the school still needs to:

- test every help-card hotline and record the date
- have a native-speaker teacher review the Filipino text
- have a guidance counselor sign off on the crisis-phrase list

The help card marks those hotlines as “Not yet verified by the school / Hindi pa nasusuri ng paaralan.” Call 911 still works for immediate danger.

## What is in this preview

- 18 bilingual lessons (English and draft Filipino)
- Six short in-browser simulations (mango sorter, fact-check, scam inbox, SOC alerts, Wi-Fi, budget PC)
- Ask Mar, an offline FAQ that stays on-topic and does not save questions
- Progress saved only on the device (no student accounts)
